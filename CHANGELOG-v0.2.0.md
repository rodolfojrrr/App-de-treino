# V0.2.0 — PC + Wi-Fi

- criada versão Windows com Electron;
- criada interface desktop para montar treinos;
- dados do PC armazenados fora da pasta de instalação;
- backup `.treino` compatível entre PC e Android;
- conexão PC ↔ celular na porta 3035;
- código de pareamento de 6 dígitos;
- celular pode receber os treinos do PC pela mesma rede Wi-Fi;
- celular pode enviar o próprio backup para o PC;
- backup automático de segurança antes de importações no computador;
- botão para liberar a porta no Firewall do Windows;
- workflow do GitHub Actions para gerar instalador `.exe`;
- workflow do APK atualizado para V0.2.0.
